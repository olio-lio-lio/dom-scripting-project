# My Daily Tasks

## About the Project

My Daily Tasks is a simple to-do list web application that helps users keep track of their daily tasks in one place.

The application was built using HTML, CSS, and JavaScript. Users can add tasks, mark tasks as completed, and delete tasks. The app also saves task data in the browser's local storage, so tasks remain available after refreshing the page.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser local storage

  ## Project Plan

The goal of this project was to create a simple and easy-to-use to-do list application.

My plan was to:
1. Create the basic page structure using HTML.
2. Style the application using CSS.
3. Use JavaScript to add, complete, and delete tasks.
4. Validate user input and display error messages.
5. Save tasks in local storage so they remain after refreshing the page.
6. Test the application and improve its appearance.

## Wireframe

The original layout was planned to have a heading, a short description, a text input, an Add Task button, an error message area, and a list of tasks.

## Self-Assessment

I created a working to-do list application using HTML, CSS, and JavaScript.

The application allows users to:
- Add tasks to the list.
- Show an error message when the input is empty or contains fewer than three characters.
- Mark tasks as completed.
- Delete tasks.
- Save tasks in local storage so they remain also after refreshing the page.

I also styled the application with CSS and tested the main features.

One limitation is that the completed status of a task does not currently remain after refreshing the page. This could be improved in a future version.
